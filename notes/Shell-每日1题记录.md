## 第 1 题（2026-11-08）：统计访问量最大的 3 个 IP

**数据**：`access.log`，每行形如

```
192.168.1.10 - - [08/Nov/2026:10:00:01 +0800] "GET / HTTP/1.1" 200 612
```

**答案**：

```bash
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -3
```

**输出**：

```
      4 192.168.1.10
      3 192.168.1.20
      2 192.168.1.30
```

| 段 | 作用 |
|---|---|
| `awk '{print $1}'` | 取第一列（IP） |
| `sort` | **关键**：让相同 IP 相邻 |
| `uniq -c` | 统计**相邻重复行**次数 |
| `sort -rn` | `-r` 倒序、`-n` 按数字排序 |
| `head -3` | 取前三 |

**两个考点**：
1. `uniq -c` **只合并相邻行**，不先 `sort` 会算错（4 次被算成 4 个 1 次）；
2. 第二个 `sort` 必须带 `-n`，否则 `10` 会排在 `2` 前面（字符串比较）。

**更短的写法**（参考，不要求背）：

```bash
awk '{c[$1]++} END {for (ip in c) print c[ip], ip}' access.log | sort -rn | head -3
```

## 第 2 题（2026-11-10）：统计日志里出现最多的进程名

**数据**：`messages`，每行形如

```
Nov 10 08:01:03 node1 kubelet: SyncLoop ADD pod default/hello-abc
```

**思路**（独立完成，未看答案）：先 `awk` 取 `$5` → `sort` → `uniq -c` → `sort -rn` → `head -5`。

**答案**：

```bash
awk '{print $5}' /tmp/shell-practice/messages | sort | uniq -c | sort -rn | head -5
```

**实跑输出**：

```
      4 sshd:
      4 kubelet:
      2 systemd:
      2 dockerd:
```

**批改**：五段全部正确，`$5` 正是进程名（`$1`=Nov、`$2`=10、`$3`=时间、`$4`=主机名）。

| 点 | 说明 |
|---|---|
| `sort` 前置 | 抓到了「`uniq -c` 只合并相邻同类项」这个限制 |
| 两个 4 并列 | `sshd:` 排在 `kubelet:` 前是 `sort -rn` 对相同数字按行内容排序，正常 |
| `head -5` | 「最多取 5 行」，本题只有 4 类进程，输出 4 行不算错 |
| `$5` 带冒号 | 题目只要求统计，带冒号没问题；想去掉可加 `tr -d ':'` |

**出题时的自我修正**：初始给的「预期输出」误写成 `5 kubelet`，实际 `kubelet` 与 `sshd` 各 4 次、共 4 类。
以后出题先跑一遍再给预期，不凭手数。

**可复用模式**：取列 → 排序 → 计数 → 按次数排序 → 取前 N。
换列号 / 换过滤条件就能查别的东西，例如：

```bash
awk '$9==500 {print $7}' access.log | sort | uniq -c | sort -rn | head -5
```
